Projectomschrijving

Voor de layout challenge moesten we een website kiezen en deze proberen na te maken door gebruik te maken van een Flex Box en css grid. Ik heb ervoor gekozen om de webpagina van Spotify na te maken.

Design

Om te beginnen heb ik een schets gemaakt van deze pagina. Hierdoor werd het makkelijk voor me om te bepalen waar ik alle onderdelen neer moest zetten.

Realisatie

Tijdens het bouwen van deze layout heb ik veel geleerd over hoe je Flexbox slim inzet. In de header heb ik justify-content: space-between gebruikt om de knoppen en zoekbalk goed te positioneren, wat ineens veel logischer werd toen ik ermee ging spelen.
