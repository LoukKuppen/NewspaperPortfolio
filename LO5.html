Leeruitkomst 5: Personal leadership

Om dit leerdoel aan te tonen heb ik verschillende dingen gedaan.

Feedback

Voor deze leeruitkomst heb ik ervoor gezorgd dat ik feedback vraag wanneer ik dit nodig heb. Ook zorg ik dat ik dit goed onderbouwend neerzet zodat ik goed terug kan zien wat mijn feedback was.

Core values

Ik heb onderzoek gedaan naar mezelf om te kijken hoe ik het beste te werk kan gaan. Ik heb dit gedaan door middel van een persoonlijkheidstest en een reflectie op mijn eigen werk. Hierdoor weet ik beter wat mijn sterke en zwakke punten zijn en hoe ik deze kan gebruiken in mijn werk. Ook behandel ik mijn toekomst plannen.
